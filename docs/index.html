Dragon Boat Replay

Garmin FIT → interactive map & speed chart. Private — runs in your browser.

View on GitHub Download .zip

Upload your activity

Drop a Garmin .fit or activity .zip from Garmin Connect. Watch the route on satellite imagery with a synced speed chart, then download a self-contained HTML replay or a social poster.

Privacy

Fully private: your GPS stays on your device. Nothing is uploaded to a server — parsing happens entirely in the browser.

Features

Feature Description
Satellite map Esri imagery with full route + live boat marker
Speed chart Click to jump; cursor synced with map
Playback 0.25×–4× · keyboard shortcuts · scrub slider
Share Download HTML · poster PNG · copy caption for social

Keyboard (in replay)

  • Space play / pause
  • ← → step one GPS point
  • 1–5 playback speed
